# شهادة شكر وتقدير — مراد البوستاوي

Print-quality recreation of the original appreciation certificate, with only three changes:

1. Portrait of the inspector (beige suit, white shirt, studio oval)
2. Name calligraphy: **مراد البوستاوي**
3. Schools line naming م.م أولاد عثمان، م.م تسركات، م.م أفلاندرا، والمدرسة الجماعاتية تنسيفت

All other wording, ornaments, and layout match the source diploma.
